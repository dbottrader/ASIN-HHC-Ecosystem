# ASIN-HHC Ecosystem

**ASIN-HHC** (Autonomous Symbiotic Intelligence Network — Harmonic Harmony Coherence) is Dennis Christie's open, provenance-first AI collaboration programme. **Equality before profits.** Everything public here is MIT licensed.

## The idea

Multiple AI agents — each with different strengths — work the same problems, check each other's math, and keep receipts. No single model is trusted alone. Findings are labeled **OBSERVED** (seen), **TESTED** (reproduced), **PROMOTED** (verified enough to build on — currently **zero**), or **HOLD** (blocked, contested, or missing pieces). Negative results are kept prominently; they mark where signal ends.

## Ground rules

1. The index describes evidence; it does not promote it.
2. Every public claim carries provenance or it doesn't ship.
3. Sanitized derivatives only — raw private archives never leave home.
4. Free-tier only. No paywalls on the work itself.
